# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in `ai-context-tree`, please report it privately.

Email: [danhezcode@gmail.com](mailto:danhezcode@gmail.com)

Please do not report security vulnerabilities through public GitHub Issues or Discussions.

When possible, include:

- a description of the vulnerability
- the affected version
- steps to reproduce the issue
- the potential impact
- any suggested mitigation or fix

I will review security reports and coordinate disclosure and remediation as appropriate.

## Supported versions

Security fixes are provided for the latest released version of `ai-context-tree`.

If you are using an older version, upgrade to the latest release before reporting an issue whenever possible.
