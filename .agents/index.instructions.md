## Agents Configuration

Directory containing customization infrastructure for agents and AI systems.

### Content

- **skills/** - Reusable skill definitions
- Context-specific custom instructions
- Specialized agent configuration
- Behavior prompts and guides

### Purpose

This directory enables:

- Extending and customizing AI behaviors
- Defining specialization domains
- Creating use-case-specific workflows
- Maintaining shared knowledge in a reusable way

### Integration

Agents and skills defined here integrate with:

- MCP (Model Context Protocol) servers
- Copilot Chat and other AI platforms
- Internal orchestration systems

### Best Practices

- Keep skills small and focused
- Document clear entry points
- Use versioning for breaking changes
- Regularly review for obsolescence
