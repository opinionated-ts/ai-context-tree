# Project Context Discovery

**Always use the `context-tree` skill first whenever you need to discover or locate project information.**

This includes finding:

- Files or directories.
- Relevant project resources.
- The purpose or contents of a directory.
- Documentation, configuration, source code, tests, or other resources associated with a location.
- Information about how the project is organized.

Use `context-tree` to determine **where to look before exploring the repository directly**.

Only fall back to direct search, directory listing, or other discovery methods when `context-tree` is insufficient or unavailable.
