## Skills Directory

This directory contains specialized skills that can be used by agents and AI systems for specific tasks. Each skill has its own folder with detailed documentation.

### Purpose

Skills are modules of knowledge or procedures that:

- Solve specific and well-defined problems
- Provide step-by-step guides for complex tasks
- Can be automatically activated by relevance
- Can be combined to create complex workflows

### Structure

Each skill includes:

- `SKILL.md` - Complete skill documentation
- Usage examples
- Success cases and limitations
- References to required tools or dependencies

### How to Use a Skill

1. Find the relevant skill in this folder
2. Read the `SKILL.md` to understand its purpose and scope
3. Follow the recommended steps
4. Combine multiple skills if needed

### Creating New Skills

To contribute a new skill:

1. Create a folder with a descriptive name
2. Write a `SKILL.md` with clear documentation
3. Ensure it is context-agnostic (reusable)
4. Include invocation examples
